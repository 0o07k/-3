الملفات
-------
index.html          الصفحة الرئيسية
style.css           التنسيق
data.js             الكلمات (هنا تضيف كلمات جديدة)
app.js              منطق البرنامج: بحث، فئات، نطق، تدريب الكتابة
server.js           تشغيل القاموس داخل VS Code (الأمر: node server.js)
main.js             نافذة برنامج الكمبيوتر (Electron)
package.json        إعدادات المشروع
build-windows.bat   بناء ملف تثبيت .exe على ويندوز
build-mac-linux.sh  البناء على ماك/لينكس
run.bat             تشغيل نافذة البرنامج على ويندوز
.vscode/tasks.json  مهمة تشغيل جاهزة داخل VS Code

التشغيل داخل VS Code (تلفون أو لابتوب)  <-- الطريقة الصحيحة لتطبيقك
-------------------------------------------------------------------
1) افتح مجلد dictionary-app في VS Code (File > Open Folder).
2) افتح الطرفية:  Terminal > New Terminal
3) اكتب:
       node server.js
   (أو:  npm start)
4) سيظهر رابط مثل:  http://localhost:3000/
   افتحه في متصفح التلفون/اللابتوب.
   أو داخل VS Code نفسه: اضغط F1 (أو Ctrl+Shift+P) واكتب
       Simple Browser: Show
   ثم الصق الرابط.

بديل بدون Node.js (إن كان Python موجوداً):
       python3 -m http.server 3000
   ثم افتح  http://localhost:3000

تشغيل بزر: Terminal > Run Task > "تشغيل القاموس"

الطريقة الأسهل على اللابتوب (بدون VS Code)
------------------------------------------
انقر مرتين على index.html فيفتح في المتصفح.

برنامج مستقل على اللابتوب (Electron - يحتاج إنترنت مرة واحدة)
-------------------------------------------------------------
       npm install
       npm run desktop
ملف تثبيت .exe:  انقر مرتين على build-windows.bat  (الناتج في مجلد dist)
